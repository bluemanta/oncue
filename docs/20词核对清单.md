# 20 词核对清单

这份清单只有一个用途：**让发音评测的测试有标准答案。**

`发音测试词表.md` 里那 20 个词是我按"职场常见 + 中国人易错"挑的，不是你自己报的。所以测出来的结论只能说明"工具能不能发现这类典型错误"，不能说明"工具能不能发现**你的**错误"。你核对完这一遍，它才变回你的词表。

预计 20 分钟。

## 怎么用

**分两遍，顺序很重要。**

**第一遍：先别看答案。** 只看下面第一节那 20 个词，每个都出声读一遍，凭感觉标一个：

- `稳` — 我确定我读得对
- `虚` — 我不太确定
- `蒙` — 我根本不知道怎么读

先做这一遍是因为：一旦看了答案，你就再也测不出自己原本会怎么读了。这一遍的结果本身就是数据——标了`稳`但其实读错的词，是这个产品最有价值的场景。

**第二遍：再看第二节的答案。** 对每个词标：

- `✓` — 我确实是这么错的
- `✗` — 我没这个问题（我读对了，或者我错在别的地方）
- 直接写下你真实的读法

**第三步：** 把结果告诉我，我填进 `发音测试词表.md` 的记录表，然后拿这 20 个词逐个跑真实评测，看工具能不能指出来——这就是 PRD 定的那条验收标准（≥ 16/20）。

## 第二节：答案，标 ✓ / ✗ / 你的读法

大写的音节是重音所在。

| 2 | comparable | com-PARE-able → **COM**-parable |  |
| 3 | procurement | **PRO**-curement → pro-**CURE**-ment |  |
| 4 | executive | EX-ecutive → ig-**ZEC**-utive，开头 x 发 /ɡz/ 不是 /ks/ |  |
