## 一句话

遇到一个不会读的英文单词，丢进来，一次拿到意思、读音、例句，然后读给它听，它告诉你读对了没有、哪个音读偏了。

## 为什么做这个

起点是一个很具体的场景：**工作里天天读到、写到的英文词，一到要说出口就卡住。**

不是不认识，是不确定怎么读。`preference` 的重音在哪、`colleague` 是不是读成 col-LEAGUE、`procurement` 到底怎么念——读英文材料的时候这些词都认得，但开会要说出来的那一刻，心里没底，于是绕过去，用一个更简单的词代替。

这类词有个共同特征：**写的时候天天见，说的时候从没说过。** 职场英语里这类词密度特别高：procurement、pipeline、deliverable、escalate、stakeholder。它们不在任何"高频口语词表"里，因为口语教材不覆盖办公室场景。

现有工具都只解决一段：

| 工具 | 能做到 | 缺口 |
| --- | --- | --- |
| 词典（有道、欧路） | 释义准确，有标准读音 | 不结合原句说"在这里是什么意思"；**不判断你读得对不对** |
| 口语 App（ELSA、流利说） | 能练发音、打分 | 要进它的课程体系，不能"随手遇到随手问" |
| 通用 AI（ChatGPT、Grok 这类） | 能结合语境讲解，体验最接近理想 | 依赖第三方平台；发音判断靠模型"听"，逐个音纠错不稳定 |

这个产品的直接原型，就是在 Grok bot 里手动跑通的那套用法：把句子贴进去，让它解释、注音、造例句，再读给它听。**用法成立，但工具不成立**——每次都要重新说一遍要求，发音判断也不可靠。OnCue 要做的就是把这套用法固化成一个不依赖第三方平台、发音判断可靠的工具。

所以产品的价值不在"查词"，而在**把四步压进一次操作，并且第四步（读对）做得靠谱**：

1. 知道它什么意思（在我这句话里的意思）
2. 知道它怎么读
3. 有一个我用得上的例句
4. **知道自己读得对不对**

第 4 步是别人都不做、或者做不准的那一步，也是这个产品存在的理由。

> 待补：上面是从 PRD 里还原的产品逻辑。如果要给 marketing 一个"创始人故事"，需要你补一个真实的具体瞬间——哪次开会、哪个词、当时怎么绕过去的。真实的细节比任何一段产品逻辑都有说服力。

## 产品原则：为什么界面这么空

首页只有一个输入框和一个按钮。这是刻意的，不是没做完。

- **只保留两个动作**：丢进来、读给它听。任何多出来的按钮都会让人在"遇到词的那一刻"犹豫。
- **结果全在一张卡片上，从上往下看完**，不用来回对话、不用点开下一层。卡片每次长得一模一样，看几次就形成阅读习惯，眼睛知道去哪里找重音。
- **每次只指出最主要的一个问题**。一次说出你三个音都不准，等于什么都没说。
- **说不准的事情不编**。录音太短、太吵、没听清人声，就直接说原因，不给一个看起来很专业的分数。重音明显错了但定位不到具体音节，就只给标准读法，不编一个"你读的"。
- **想听几遍听几遍**。播放是按钮，不是一条发过来的语音。

## 现在能做什么

以下都是线上已经跑通的：

| 能力 | 具体表现 |
| --- | --- |
| 丢进来 | 打字或粘贴，首页有一键粘贴按钮。可以贴整句，也可以只给一个词 |
| 看懂 | 整句时告诉你这个词**在这句话里**是什么意思，再给 2–3 个常用义项，职场义项排前面 |
| 会读 | 美式音标、标出重音在哪个音节、中国人最容易读错的 1–2 处以及怎么改 |
| 听 | 单词有慢速和常速两个按钮，例句可以播放。同一段音频只合成一次，之后秒出 |
| 例句 | 1–2 句职场和销售场景的句子，带中文翻译，每句能播放 |
| 读对 | 按住麦克风跟读，松开就提交。结果分三档：读对了 / 基本对（指出 1 处问题）/ 不对（给慢读示范，引导再读一遍） |
| 读单词 vs 读例句 | 读单词时精确到哪个**音素**读错、重音落在哪；读例句时指出哪个**词**读得最不稳 |
| 像 App 一样用 | 手机上"添加到主屏幕"，有自己的图标和名字，打开没有浏览器地址栏 |

一个真实的例子（线上实测过）：把 `Let's check my schedule for next week.` 贴进去，卡片会告诉你 schedule 在这里是"日程安排"，重音在第一个音节，开头是 /sk/ 不是 /ʃ/；跟读时如果把 schedule 读成 shed-ule，它会指出是 schedule 这个词读得最不稳，而不是去纠一个无关的冠词。

## 现在不能做什么

这些不是 bug，是明确没做：

- **没有账号、没有历史记录。** 关掉页面，查过的词就没了。（"查词记录"和"错音本"在计划里，没做）
- **没有复习提醒。**
- **不能截图输入。** 用手机自带的文字识别先复制出英文，再粘贴。
- **电脑上不能划词查。** 可以在电脑浏览器里打开用，但没有插件。
- **界面上只有美音。** 腾讯云目前七个英文音色实听全是美音，没有英音可选，所以切换按钮暂时去掉了。
- **一句话里有多个生词时，只查一个。**
- **没有课程、词书、打卡、排行榜。** 也不打算做。

## 目标人群

### 核心人群（产品就是为他们做的）

**英文读写够用、听说偏弱、每天要碰英文工作材料的职场人。**

画像：

- 30–45 岁，外企 / 出海公司 / 有海外客户的国内公司
- 岗位集中在销售、售前、BD、产品、咨询、项目管理——**要开口说英文，但不是靠英文吃饭**
- 英文邮件写得不错，英文文档读得下来，一开口就换成简单词
- 已经过了"学英语"的年纪和心态：不会去报课、不会打卡、不做题。**只在遇到问题的那一秒需要一个答案**

他们的原话大概是：

> "这个词我天天写，但我不知道怎么念。"
> "开会的时候我就绕过去了，用了另一个词。"
> "我不想再学英语了，我就想把这个词读对。"

为什么这群人最值得做：需求发生频率高（每天读英文材料）、痛点具体（不是"想提高英语"，是"这个词怎么读"）、且现有工具确实没覆盖。

### 相邻人群（可能成立，但要验证）

| 人群 | 为什么可能成立 | 顾虑 |
| --- | --- | --- |
| 出海创业者、跨境电商、外贸业务员 | 要跟海外客户开口，需求更急；社群密集、好触达 | 场景偏销售口语，例句库现在正好对口，值得优先试 |
| 技术人员（读英文文档、开英文会） | 专业词汇密度极高，且几乎全是"只写不说"的词 | 他们对"读得准"的容忍度高，可能觉得"能听懂就行"，付费意愿待验证 |
| 要做英文汇报、面试的人 | 有明确的、有时间压力的目标，动机强 | 需求是一阵一阵的，用完就走，留存差 |
| 口译、英语培训从业者 | 专业需求 | 他们的标准比工具高，容易挑出不准的地方 |

### 明确不适合的人群（marketing 请不要往这里投）

- **学生、K12、家长**：他们要的是课程、体系、进度、成绩，这个产品一个都不提供。
- **零基础、想"学英语"的人**：产品假设你已经读得懂，只是不会读。对零基础的人它什么也解决不了。
- **备考党（雅思托福口语)**：他们需要题型、评分标准、模考。ELSA、流利说在这块做了很多年，我们没有任何优势。

## 现在做到哪一步了

原计划两周做出第一版（10/11 上线），**实际 9/27 就已经上线**，比计划快了约两周。

| 里程碑 | 计划 | 实际 |
| --- | --- | --- |
| 结果卡片 + 读音（F1/F3/F4） | 9/28–10/4 | 已完成 |
| 跟读评测 + 上线（F5） | 10/5–10/11 | 已完成，已上线 HTTPS 域名 |
| 发音评测服务选型实测 | 10/11 前 | **还没做**（见下） |
| 自用验证（每天真实使用） | 10/12–10/25 | 还没开始 |
| 决定下一步 | 10/26 | — |

**两件还没做的事，都和"能不能推广"直接相关：**

1. **发音评测准不准，还没量过。** PRD 定的验收标准是"20 个常错词里，能准确指出问题的 ≥ 16 个"。这个数还没测，所以"能指出你哪个音读错"这个核心卖点，目前是**没有数据支撑的**。评测的三档分数线也还是默认值，没有依据可调。
2. **自用验证期还没开始。** PRD 的主指标是"自己连续 14 天使用、每天至少 3 次"。这条是当初给自己定的"值不值得继续做"的判断标准。

## 技术与成本（通俗版）

- 手机网页，跑在自己已有的腾讯云服务器上，用已备案的域名，HTTPS（浏览器只允许 https 网页使用麦克风）。
- 释义和例句用腾讯云上的 DeepSeek；读音用腾讯云语音合成；发音评测用腾讯云智聆口语评测。三者都通过一层"转换插头"调用，以后换服务商只换插头，产品不动。
- 合成好的读音存在腾讯云对象存储里，同一段文字只合成一次，之后直接取——又快又省钱。
- **第一版没有数据库**，所以也没有任何用户数据留存。
- 成本上服务器和域名是现成的，新增的只有按次计费的三项服务。自用量级每月通常几十元以内。**但推广量级的成本还没算过**，见 `试点前置清单.md`。

## 数据与隐私（现状，不是目标状态）

- 跟读录音只用于当次评测，不保存。
- 没有数据库，所以查过的词、读过的句子都没有存下来。
- **但是**：粘贴进来的内容会发送给腾讯云的大模型和评测服务处理。如果你贴的是客户 RFP 的原句，那句话就发出去了。
- **目前页面上没有任何关于这件事的提示。** 自用可以接受，给别人用之前必须加。
