# 发音测试词表

这份表是第二周选发音评测服务商的依据，同时顺带核对两件事：大模型给的音标准不准、哪个模型档位更合适。

PRD 的验收标准：**20 个常错词里，工具能准确指出问题的 ≥ 16 个。** 达不到就换服务商或改反馈方式。

## 关于这份词表的一个说明

下面 20 个词是**我挑的**，不是你自己报的。按"职场 / 销售 / RFP 场景常见 + 中国人容易读错"两个条件选的，并且刻意覆盖了不同的出错类型（重音、字母与读音对不上、不发音的字母、词尾）。

**这意味着测试结论会弱一档**：它证明的是"工具能不能发现这类典型错误"，而不是"工具能不能发现**你的**错误"。真正的验收还是得看你实际用起来准不准。

所以第四列请你花几分钟过一遍——**这是把它变回"你的词表"的关键一步**。核对比回忆省事得多。

## 为什么"你核对"这一列重要

因为我们要判断的不是"工具有没有反应"，而是**工具说的对不对**。

比如你读 `schedule`，工具说"重音错了"——但如果你重音其实没问题、错的是开头的 /sk/，那这次算**误报**，不能计进那 16 个。得有个标准答案来对照。
