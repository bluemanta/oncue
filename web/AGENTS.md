# 项目协作约定

此工程由 project-starter 0.1.0 创建。先读 tech-profile.json、STACK.md 和 README.md，再开始开发。

- 用户当前指令优先。沿用本项目模板，不因 Agent/设计工具默认偏好换框架。
- TypeScript strict；默认 npm；保留 package-lock.json；React 与 react-dom 同版本。
- 普通 Web 接口与页面共用 TypeScript 工程。只有文档/数据/模型处理或已有 Python 引擎等明确收益时才增加 Python，并记录用途。
- 在 tech-profile.json 记录数据库、运行方式和技术例外。常规默认选型直接推进；真实外部影响按用户授权执行，不把技术例外变成重复审批。
- 不默认添加登录、支付、邮件、数据库、云账号或独立后台服务。需要外部服务时先确定部署与数据边界。
- 开发服务仅绑定 127.0.0.1；端口冲突时先确认归属，不结束其他项目的进程。
- 私人数据放 data/ 或仓库外；凭证放 .env.local；只提交不含真实值的 .env.example。
- 修改后运行 npm run check，涉及构建/路由/依赖时运行 npm run build；按改动风险验证一条主流程。结构通过不等于浏览器/用户验收。
- 不删除测试或绕过检查来掩盖问题；无需为微小文案或可逆样式改动增加完整测试套件。
- Git 初始化、提交、推送、合并以及发布不由代码编辑自动授权。
- 模板升级只影响新项目。已有项目按实际需求升级并记录；不要直接修改 stack-baseline.json 来使检查变绿。
